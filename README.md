# おすすめや書房 書籍紹介アーカイブ

[おすすめや書房のX](https://x.com/s_aokoshi)で紹介した書籍を、月ごとのExcelにまとめています。

Excelには掲載日、投稿タイミング、書籍の区分、書名、著者、紹介文、個別の紹介ポストへのリンクを掲載します。フィルターや検索で本を探し、気になる本の紹介ポストを開けます。

公開済みの月から、以下へダウンロードリンクを追加します。
